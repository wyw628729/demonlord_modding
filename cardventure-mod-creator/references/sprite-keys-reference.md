### Mod 自定义武器（ID ≥ 1320）

Mod 武器的精灵 key 完全由作者自定义，通过 `WeaponModAPI.RegisterWeapon` 的 `spriteKeys` 参数注册后，游戏会从 WorkshopSpriteOverrideDB 优先查找。

游戏通过 `TryGet(unitType, key)` 查找精灵，玩家角色的 unitType 固定为 1000。因此，武器形态精灵**必须放在 `UnitSprites/1000/` 目录**，而不是武器 ID 目录。

```
UnitSprites/
  weapon1320.png          ← 武器图标（放根目录，用 weapon + 武器ID 命名）
  1000/                   ← 玩家形态精灵（魔王 ID 固定为 1000）
    charging11320.png     ← 以 key 名命名，key 中嵌入武器 ID 以避免冲突
    firing1320.png
```

在代码 Mod 注册时：

```csharp
var profile = WeaponModAPI.RegisterWeapon(
    id: 1320,
    // ...
    spriteKeys: new[] { "charging11320", "firing1320" }
);
```
